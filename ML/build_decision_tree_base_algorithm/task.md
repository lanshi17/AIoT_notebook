# Task 3
* 分别举例说明，决策分类树与决策回归树的数据，是否需要进行归一化处理？
1. 决策分类树举例（Classification Tree）
场景：预测用户是否会购买某款游戏（是/否）。
特征：用户年龄（范围 10岁 ~ 80岁）。
不归一化时：决策树会遍历所有可能的年龄值，发现当 年龄 <= 25 时，购买率最高（基尼不纯度下降最多）。于是生成规则：if 年龄 <= 25: 买 else: 不买。
归一化后：假设年龄被标准化为均值为0，标准差为1的分布（范围大约 -1.5 ~ 2.0）。决策树再次遍历，会发现当 标准化年龄 <= -0.6 时，效果最好。
结果对比：标准化年龄 <= -0.6 在数学上完全等价于 原始年龄 <= 25。树的拓扑结构、深度、分类结果没有任何改变，但归一化却白白浪费了计算时间。
2. 决策回归树举例（Regression Tree）
场景：预测二手房的价格（连续数值，如 500万）。
特征：房屋面积（范围 50平米 ~ 300平米）。
不归一化时：回归树通过计算方差减少量（或MSE减少量）来寻找分裂点。它发现按 面积 <= 120平米 划分，能让左右子节点的房价方差之和最小。
归一化后：面积被缩放到 [0, 1] 之间。树寻找分裂点，发现按 归一化面积 <= 0.35 划分效果最好。
结果对比：同样，0.35 等价于 120平米。左右子节点包含的样本完全一致，计算出的预测值（子节点样本的目标变量均值）也完全一致。

* 为什么逻辑斯蒂回归和岭回归算法需要进行归一化处理？
如果不做归一化：
模型训练时间会变长（梯度下降震荡）。
模型可能会认为“复习时间”比“做题数”重要得多，仅仅因为“做题数”的数值大导致其权重小，从而被 L2 正则化错误地抹杀了。
输出的概率值可能会因为数值溢出（大数值乘以大权重）而出现 NaN（Not a Number）或极端值。

需要归一化：所有基于距离的算法（KNN、SVM、K-Means）、所有基于梯度下降的算法（神经网络、LR）、所有带正则化的线性模型（Ridge、Lasso、ElasticNet）。
不需要归一化：所有基于树的算法（决策树、随机森林、GBDT）、基于概率分布且不受尺度影响的算法（朴素贝叶斯）。
